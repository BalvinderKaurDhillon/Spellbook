# The Witching Hour 

## Music

The folder currently includes a 15-second clip created from the audio file supplied by the user. The page starts it only after the visitor opens the book, then loops it while the book remains open.

The clip uses this exact filename:

`licensed-somebodys-watching-me-clip.mp3`

When the book opens, the site automatically uses that file and repeats it until the visitor closes the book or leaves the page. Without it, the clearly labeled placeholder plays instead. Check that your rights or licence cover online/public playback before publishing.
