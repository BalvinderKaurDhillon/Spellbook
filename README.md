# The Witching Hour — local preview

Open `index.html` through a local web server, press the bat to enter, then click the spellbook.

## Upload to GitHub

Upload every file in this folder to the root of a GitHub repository. To publish it with GitHub Pages, open the repository's **Settings → Pages**, choose **Deploy from a branch**, then select the `main` branch and `/ (root)` folder.

Keep the filenames unchanged so the font and music continue to load.

The bundled `UnifrakturCook.ttf` display font is used under the SIL Open Font License; its licence is included as `OFL-UnifrakturCook.txt`.

## Music

The folder currently includes a 15-second clip created from the audio file supplied by the user. The page starts it only after the visitor opens the book, then loops it while the book remains open.

The clip uses this exact filename:

`licensed-somebodys-watching-me-clip.mp3`

When the book opens, the site automatically uses that file and repeats it until the visitor closes the book or leaves the page. Without it, the clearly labeled placeholder plays instead. Check that your rights or licence cover online/public playback before publishing.
